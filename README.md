# sgm-full-version
SGM (Students Grades Management) is a comprehensive web application for managing student academic records. It allows administrators to track students, subjects, and grades across multiple years and filieres. Features include grade entry, real-time statistics, filtering by year/filiere/subject, student ranking, and search functionality.

## 🎯 Overview

**SGM (Students Grades Management)** is a comprehensive web-based application designed to streamline academic record management. Built with PHP and MySQL, it provides educational institutions with a powerful, intuitive platform to manage students, subjects, and grades across multiple years and filieres.

## ✨ Features

### Core Functionality
| Feature | Description |
|---------|-------------|
| 📝 **Student Management** | Add, edit, and delete student records with personal information |
| 📊 **Grade Management** | Record and update grades with automatic calculations |
| 📚 **Subject Organization** | Manage subjects with coefficients for different filieres |
| 🔍 **Smart Filtering** | Filter results by year, filiere, or specific subject |
| 📈 **Statistics Dashboard** | Real-time statistics including totals and averages |
| 🏆 **Ranking System** | Compare student performance across classes |
| 🔎 **Search Functionality** | Quick search for students or specific results |

### Technical Features
- ✅ **CRUD Operations** - Complete Create, Read, Update, Delete functionality
- ✅ **Responsive Design** - Works on desktop, tablet, and mobile devices
- ✅ **SQL Injection Protection** - Using PDO prepared statements
- ✅ **Session Management** - Secure user authentication
- ✅ **Real-time Updates** - Instant data refresh after operations
